Two Kinds of Risk

Last week we measured volatility. This week we decompose it.

A stock’s total volatility \(\sigma_i\) has two ingredients:

  • Systematic risk: co-moves with the market. Cannot be diversified away.
  • Idiosyncratic risk: stock-specific. Vanishes in a well-diversified portfolio.

The market model is the simplest tool to separate the two. And it gives us a single number that captures systematic risk: \(\beta\).

1. The Market Model

A linear regression of stock on market

NoteMarket model

\[R_{i,t} = \alpha_i + \beta_i\, R_{m,t} + \varepsilon_{i,t}\]

  • \(R_{i,t}\): stock \(i\)’s return on day \(t\).
  • \(R_{m,t}\): the market’s return on day \(t\).
  • \(\alpha_i\): intercept — average performance unrelated to the market.
  • \(\beta_i\): slope — the sensitivity of the stock to the market.
  • \(\varepsilon_{i,t}\): residual — the part the market cannot explain.

In R, this is a one-line call to lm().

What does \(\beta\) mean?

\[\beta_i = \frac{\mathrm{Cov}(R_i,\,R_m)}{\mathrm{Var}(R_m)}\]

  • \(\beta > 1\): stock amplifies market moves — more cyclical.
  • \(\beta = 1\): stock moves with the market on average.
  • \(0 < \beta < 1\): stock moves with the market but less than 1-for-1 — defensive.
  • \(\beta < 0\): stock moves against the market — rare; gold and some hedges.

For tech stocks like NVDA we typically see \(\beta > 1\); for utilities and consumer staples, \(\beta < 1\).

2. Estimating \(\beta\) in R

The data

stock_ticker  <- "NVDA"
market_ticker <- "^GSPC"   # S&P 500
start_date    <- "2020-01-01"
end_date      <- "2026-01-01"

stock_data  <- tq_get(stock_ticker,  from = start_date, to = end_date)
market_data <- tq_get(market_ticker, from = start_date, to = end_date)

Three years of daily data is a typical estimation window.

Computing daily returns

stock_returns <- stock_data |>
  tq_transmute(select     = adjusted,
               mutate_fun = periodReturn,
               period     = "daily",
               col_rename = "stock_return")

market_returns <- market_data |>
  tq_transmute(select     = adjusted,
               mutate_fun = periodReturn,
               period     = "daily",
               col_rename = "market_return")

returns <- left_join(stock_returns, market_returns,
                     by = "date") |>
  na.omit()

tq_transmute() with periodReturn is the tidyquant shorthand for the discrete-return formula from Week 3.

Running the regression

model <- lm(stock_return ~ market_return, data = returns)
summary(model)

What to look for in the output:

  • Estimate for market_return: this is \(\hat\beta\).
  • Estimate for (Intercept): this is \(\hat\alpha\).
  • Pr(>|t|): is \(\beta\) statistically distinguishable from 0?
  • Multiple R-squared: fraction of variance explained by the market.

Extracting \(\hat\beta\) cleanly

library(broom)

beta_hat <- tidy(model) |>
  filter(term == "market_return") |>
  pull(estimate)

cat("Estimated beta for", stock_ticker, "=",
    round(beta_hat, 2), "\n")
Estimated beta for NVDA = 1.78

For NVDA over 2020–2022, this comes out around 1.6 — NVDA tended to move about 1.6% for every 1% move in the S&P 500.

3. Visualizing the Regression

A scatter plot with the fitted line

Code 
returns$fit <- predict(model)

highchart(width = 1280) |>
  hc_title(text = "NVDA vs. S&P 500 --- Linear Fit") |>
  hc_xAxis(title = list(text = "Market Return")) |>
  hc_yAxis(title = list(text = "Stock Return")) |>
  hc_add_series(data = returns, type = "scatter",
                hcaes(x = market_return, y = stock_return),
                name = "Daily Returns") |>
  hc_add_series(data = returns[order(returns$market_return), ],
                type = "line",
                hcaes(x = market_return, y = fit),
                name = "Fitted line") |> 
  hc_tooltip(valueDecimals = 2)

The slope of that line is your eyeball estimate of \(\beta\).

4. Idiosyncratic Risk

What the regression can’t explain

The residuals \(\hat\varepsilon_{i,t} = R_{i,t} - \hat{\alpha} - \hat\beta\, R_{m,t}\) are the stock-specific portion of returns.

NoteIdiosyncratic volatility

\[\sigma_{\varepsilon,i} = \mathrm{sd}\!\left(\hat\varepsilon_{i,t}\right)\]

residuals_i <- resid(model)
idio_vol    <- sd(residuals_i)
cat("Idiosyncratic volatility:",
    round(idio_vol, 4), "\n")
Idiosyncratic volatility: 0.0238

Decomposition of variance

In population:

\[\underbrace{\sigma_i^2}_{\text{total}} \;=\; \underbrace{\beta_i^2\, \sigma_m^2}_{\text{systematic}} \;+\; \underbrace{\sigma_{\varepsilon,i}^2}_{\text{idiosyncratic}}.\]

sigma_total <- sd(returns$stock_return)
sigma_mkt   <- sd(returns$market_return)
sys_part    <- beta_hat^2 * sigma_mkt^2
idio_part   <- idio_vol^2

c(total_var = sigma_total^2,
  systematic = sys_part,
  idiosyncratic = idio_part)
    total_var    systematic idiosyncratic 
 0.0011217331  0.0005529311  0.0005688020

systematic + idiosyncratic should approximately equal total_var — the analysis-of-variance identity behind the market model.

5. Why \(\beta\) Matters

\(\beta\) is what the CAPM prices

The Capital Asset Pricing Model (Sharpe, 1964) says expected excess return depends only on \(\beta\):

NoteCAPM

\[E[R_i] - R_f = \beta_i \,\bigl(E[R_m] - R_f\bigr)\]

  • High-\(\beta\) stocks should earn higher expected returns.
  • Idiosyncratic risk should not be priced — you can diversify it away.

The empirical evidence is mixed (the “low-beta anomaly”), but \(\beta\) remains the single most-cited measure of a stock’s market risk.

Course connections

What we built this week will be the foundation for two later ideas you’ll meet if you continue:

  • Cumulative abnormal returns (CAR) in event studies. The market model predicts a stock’s “normal” return; whatever the stock does above and beyond that prediction around an event date is the abnormal return.
  • Multi-factor models (Fama-French, Carhart). We replace the single market return with several factor portfolios. The R syntax barely changes: lm(R_i ~ MKT + SMB + HML).
