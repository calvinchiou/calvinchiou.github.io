What Is a Return?

The investor’s most basic question

You bought a stock at NT$100. It’s now NT$110.

How much did you make?

Two equally valid answers:

  • In money: NT$10.
  • In percentage: 10%.

This week is about percentage returns — and the fact that there are two different definitions, both correct, both used in practice.

1. Discrete (Simple) Returns

Definition

NoteDiscrete return

\[R_t = \frac{P_t}{P_{t-1}} - 1 = \frac{P_t - P_{t-1}}{P_{t-1}}\]

The intuitive percentage change. If \(P_{t-1} = 100\) and \(P_t = 110\), then \(R_t = 10\%\).

This is the version you see in newspapers, brokerage statements, and industry research.

Computing it in R with dplyr

apple <- tq_get("AAPL", from = "2023-01-01", to = "2026-01-01")

apple <- apple |>
  arrange(date) |>
  mutate(R_disc = adjusted / lag(adjusted) - 1)

lag() shifts the column down one row — the previous day’s price.

2. Continuous (Log) Returns

Definition

NoteContinuous (log) return

\[r_t = \ln\!\left(\frac{P_t}{P_{t-1}}\right) = \ln P_t - \ln P_{t-1}\]

The log return is the instantaneous-growth-rate version of return — the counterpart of continuous compounding from Week 2.

For small changes, \(r_t \approx R_t\). They diverge for large moves.

Discrete vs. continuous — side by side

apple <- apple |>
  mutate(R_disc = adjusted / lag(adjusted) - 1,
         r_log  = log(adjusted / lag(adjusted)))

For a typical daily move of \(\pm 1\%\), the two are nearly identical. For a \(+50\%\) jump, \(R = 0.50\) but \(r = \ln(1.5) = 0.405\).

When to use which?

Discrete \(R\) Continuous \(r\)
Interpretation Simple % change Log-based, continuous
Time-additive? No Yes
Cross-section sum Yes (portfolio) No
Where used Industry, reporting Academic research, modelling

The time-additivity of log returns is what makes them the standard in econometrics: a 2-day log return is just the sum of two daily log returns.

3. Time vs. Cross-section Additivity

Why log returns are time-additive

Over \(n\) days: \[\frac{P_T}{P_0} = \prod_{t=1}^{T}\frac{P_t}{P_{t-1}} \quad\Rightarrow\quad \ln\!\frac{P_T}{P_0} = \sum_{t=1}^{T} r_t.\] So \(r_{0 \to T} = r_1 + r_2 + \cdots + r_T\). Sum them.

But the same formula in discrete form is: \[1 + R_{0 \to T} = \prod_{t=1}^{T} (1 + R_t).\] So \(R_{0 \to T} \ne R_1 + R_2 + \cdots + R_T\). Compound them.

Why discrete returns are cross-section-additive

For a portfolio with weights \(w_i\) summing to 1:

\[R_p = \sum_{i=1}^{N} w_i\,R_i \qquad \text{(exactly)}\] This is exact for discrete returns, and only approximate for log returns.

Practical rule of thumb:

  • Aggregating across stocks at one point in time \(\to\) discrete.
  • Aggregating across time for one stock \(\to\) continuous.

4. Multi-period Returns

Cumulative discrete return

\[R_{\text{cum}} = \prod_{t=1}^{T}(1 + R_t) - 1\]

apple <- apple |>
  mutate(cum_R = cumprod(1 + coalesce(R_disc, 0)) - 1)

cumprod() does the running product; coalesce(R_disc, 0) replaces the first NA with 0 so the cumulative product starts from 1.

Cumulative log return

\[r_{\text{cum}} = \sum_{t=1}^{T} r_t\]

apple <- apple |>
  mutate(cum_r = cumsum(coalesce(r_log, 0)))

Just cumsum() — nothing more.

To convert back to a discrete cumulative return: \(R_{\text{cum}} = e^{r_{\text{cum}}} - 1\).

5. Buy-and-Hold Return

A passive strategy in one line

The simplest possible “strategy”: buy on day 0, never trade. The return over any horizon is just the price ratio:

\[R_{\text{BH}} = \frac{P_T}{P_0} - 1\]

apple |>
  summarise(BH_return = last(adjusted) / first(adjusted) - 1)
# A tibble: 1 × 1
  BH_return
      <dbl>
1      1.21

It sounds trivial — but as we’ll see in Week 6, a well-chosen buy-and-hold often beats more complex active strategies. Don’t dismiss it.

6. Visualizing Returns

A return time-series

Code 
highchart(type = "stock", width = 1280) |>
  hc_add_series(apple, type = "line",
                hcaes(x = date, y = R_disc * 100),
                name = "AAPL Daily Return (%)") |>
  hc_title(text = "AAPL Daily Returns 2023") |>
  hc_yAxis(title = list(text = "Return (%)")) |> 
  hc_tooltip(valueDecimals = 2, valueSuffix = " %")

Cumulative-return chart

Code 
highchart(type = "stock", width = 1280) |>
  hc_add_series(apple, type = "line",
                hcaes(x = date, y = cum_R * 100),
                name = "Cumulative Discrete Return") |>
  hc_add_series(apple, type = "line",
                hcaes(x = date, y = cum_r * 100),
                name = "Cumulative Log Return") |>
  hc_title(text = "AAPL 2023 --- Two Ways to Measure Cumulative Return") |>
  hc_yAxis(title = list(text = "%")) |> 
  hc_tooltip(valueDecimals = 2, valueSuffix = " %")

The two lines diverge slightly as returns accumulate — the visual proof of compounding.
